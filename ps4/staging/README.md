# Entrada do pacote PS4

Coloque aqui o `eboot.bin` produzido por um port nativo PS4 do MINEPLUS e crie `sce_sys/icon0.png` (PNG RGB 512x512, sem transparência). O script `bash ps4/package.sh` gera o SFO, GP4 e PKG quando os requisitos estiverem presentes. O projeto Godot/GDScript atual ainda não gera esse EBOOT.
